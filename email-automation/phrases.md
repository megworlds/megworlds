# メール頻出フレーズ集（三矢さん）

> 送信済みメール（社外向け）から抽出した、実際によく使われている言い回し集。
> メール下書き自動化の「素材」として使う。`{{ }}` は毎回差し替える箇所。
> **これは叩き台です。違う・使わない・足したいフレーズがあれば直してください。**

---

## トンマナ（文体ガイド）

三矢さんの文体の原則。下書きはこれに沿う。違和感のあった言い回しは例として足していく。

- 硬すぎる定型ビジネス語は避け、**自分の言葉で丁寧に**伝える。
- クッション言葉（恐れ入りますが／大変恐縮ですが 等）は使うが、**大げさにしすぎない**。
- 事実（金額・型番・日付・仕様）は**創作しない**。分からなければ「社内で確認のうえ改めてご連絡」の形にする。
- 一文は**長くしすぎず、簡潔に**。

### 避けたい言い回し（例）
- 「正確を期すため」→「念のため確認のうえ」など、自分の言葉に。

## 0. 共通パーツ（どのメールでも使う土台）

### 書き出し
```
{{相手会社名}} {{宛名}}様
お世話になっております。Natureの三矢です。
```
- 初めての相手：`お世話になっております。Natureの三矢と申します。`
- 社名を添えるとき：`{{相手会社名}} {{部署名}} {{宛名}}様`

### 冒頭のひとこと（受信への反応）
- `ご連絡いただきありがとうございます。`
- `ご連絡ありがとうございます。`
- `早速ご確認いただき、ありがとうございます。`
- `この度は、ご連絡いただきましてありがとうございます。`

### 受領・了解を伝える
- `{{内容}}の旨、承知いたしました。`
- `{{内容}}につきまして承知いたしました。`
- `確かに拝受いたしました。`

### 結び
- `引き続きよろしくお願いいたします。`
- `何卒よろしくお願いいたします。`
- `当日はどうぞよろしくお願いいたします。`（会議確定時）
- `ご不明な点等ございましたら、お気軽にご連絡ください。`

### 署名
- 本文の**末尾**は次の1行で締める：
```
Nature / 三矢
```
- その下の正式署名（下記）は **Gmailのデフォルト署名**として自動挿入される。本文には書かない。
```
Nature株式会社 三矢 めぐみ
https://nature.global/
```
- ⚠️ 注意：Gmailの下書きをツールで自動作成する場合、デフォルト署名が自動で入らない可能性がある。仕組み構築時に要検証（入らないなら下書きに正式署名まで含める）。

## 1. 会議調整系

### 1-1. 打ち合わせを依頼する（本文の入り）
- `{{用件}}について、認識合わせのお時間をいただきたく、ご連絡いたしました。`
- `{{用件}}について事前にすり合わせをさせていただきたく、以下の日程で{{所要時間}}程度、お打ち合わせのお時間をいただけますでしょうか。`
- `本件、{{引き継ぎ元}}より引き継ぎ、私の方で対応させていただきます。`

### 1-2. 候補日を送る
```
お打ち合わせにつきまして、以下の日程でご都合はいかがでしょうか。
・{{月日（曜）}} {{時間帯}}
・{{月日（曜）}} {{時間帯}}
・{{月日（曜）}} {{時間帯}}
ご都合のよい日時をお知らせください。
```
- 候補が合わなかったときの再提示：
  `恐れ入りますが、ご提示いただいた日程での調整が難しいため、以下の日程ではいかがでしょうか。`
  `最短で可能な日時を改めて提示させていただきます。`

### 1-3. 候補日を受領する／日程を確定する
- `{{日時}}にて承知いたしました。`
- `Teams発行させていただきましたので、よろしければこちらでお繋ぎいただければと思います。`
- `teams発行もありがとうございます。当日はどうぞよろしくお願いいたします。`
- （こちらが会議URLを送る）`{{ツール}}を発行いたしましたので、よろしければこちらでお繋ぎいただければと思います。`

### 1-4. 会議後のお礼＋ネクストアクション＋資料送付
```
先日はお打ち合わせのお時間を頂戴しまして誠にありがとうございました。
お打ち合わせで投影いたしました資料を添付いたします。よろしければご確認いただけますと幸いです。
{{ネクストアクション：例）社内にて〇〇の準備を進め、改めてご連絡いたします。}}
```
- 追加確認があるとき：`先日ご共有いただきました「{{資料名}}」について、追加で何点か確認させてください。`

## 2. 注文・納品・請求系

### 2-1. 注文書を受領した／納期を知らせる
- `注文書をお送りいただき、ありがとうございます。確かに拝受いたしました。`
- `{{日付}}出荷、{{日付}}納品にて調整いたします。`
- `本日出荷で対応できる見通しになりましたので、取り急ぎの報告とさせていただきます。諸々の手続きは追っての対応とさせてください。`
- （注文請書）`注文請書を添付にてお送りいたします。ご確認のほどよろしくお願いいたします。`

### 2-2. 発送・追跡番号の連絡
```
{{製品名}}の発送手続きが完了いたしましたので、ご連絡いたします。
運送会社：{{運送会社}}
お届け指定日：{{日付}}
送り状No（追跡番号）：{{番号}}
お手数ですが、着荷のご確認のほどよろしくお願いいたします。
```

### 2-3. 請求書を送る
```
{{件名の内容}}（{{月}}分）のご請求書を添付にて送付いたします。
ご査収のほどよろしくお願いいたします。
ご不明な点等ございましたら、お気軽にご連絡ください。
```

### 2-4. 請求書送付を依頼・督促する
```
{{対象}}のご請求書につきまして、現時点で未受領となっております。
弊社の経理締めの都合上、大変恐縮ですが、可能であれば{{営業日数}}営業日までにご送付いただけますと幸いです。
お手数をおかけいたしますが、ご対応のほどよろしくお願いいたします。
```
- 提出遅延への配慮：`提出時期によっては社内処理の都合上、お支払い期日のご相談をさせていただく場合もございますので、その際は何卒ご了承ください。`

## 3. 資料・契約書の確認系

### 3-1. 契約書・資料を送付して確認を促す
- `{{書類名}}を添付にてお送りいたします。ご確認のほどよろしくお願いいたします。`
- `よろしければご確認いただけますと幸いです。`

### 3-2. 契約書・資料を受領して確認する旨を伝える
```
{{書類名}}をお送りいただき、ありがとうございます。確かに拝受いたしました。
社内にて内容を確認のうえ、改めてご連絡いたします。
```

### 3-3. 契約締結の進め方（NDA / クラウドサイン）
```
締結につきましては、弊社よりクラウドサインにて署名依頼をお送りすることも可能ですが、いかがでしょうか。
その場合、署名者様のお名前とメールアドレスをご共有いただけますと幸いです。
```
- 日付確認：`契約書末尾の日付について、{{日付}}として問題ございませんでしょうか。ご確認いただけますと幸いです。`

## 4. お客様サポート系（回答の前後をつくる）

> 回答の中身（技術的な答え）はケースバイケースなので固定しない。
> 「入り」と「締め」＋確認を促す言い回しだけをテンプレ化する。

### 4-1. 入り（お礼＋回答の前置き）
```
このたびは、{{製品名／件名}}についてお問い合わせいただき、誠にありがとうございます。
ご質問について、以下のとおりご回答いたします。
```
- 回答が遅れたとき：`お問い合わせのご回答にお時間を頂戴しまして恐れ入ります。`
- 社内確認が必要なとき：`恐れ入りますが、社内にて確認のうえ、改めてご連絡いたします。`

### 4-2. 状況確認を依頼する（切り分け）
```
恐れ入りますが、下記の状況についてご確認いただけますでしょうか。
① {{確認項目}}
② {{確認項目}}
```
- `1点ご確認ですが、{{確認内容}}でしょうか。`

### 4-3. 締め
- `ご不明な点がございましたら、お気軽にお知らせください。`
- `弊社でも引き続き確認・調査を進めており、追加でお伝えできることがございましたら、改めてご連絡させていただきます。`
- `何卒よろしくお願いいたします。`

## 6. お断り・お詫び系

### 6-1. 相手からの「見送り」への返答
```
今回は見送りとのこと、承知いたしました。
もし差し支えなければ、今後の対応の参考にさせていただきたく、見送りとされた理由をお伺いできますでしょうか。
お忙しいところ恐れ入りますが、よろしくお願いいたします。
```
- 理由をもらった後：`他社製品も含めてご比較・ご検討いただいた上でのご判断とのこと、承知いたしました。`
- ねぎらい：`現地調査の対応につきましても温かいお言葉をいただき、大変嬉しく存じます。担当者にもお伝えさせていただきます。`

### 6-2. こちらからお断りする（依頼に沿えないとき）
```
せっかくのご相談にもかかわらず、{{沿えない理由}}のため、ご希望に沿うことができません。
大変恐縮ではございますが、何卒ご了承くださいますようお願い申し上げます。
```

### 6-3. お詫び（返信・対応の遅れ）
- `ご返信までお時間をいただいてしまい、大変申し訳ございませんでした。`
- `お問い合わせのご回答にお時間を頂戴しまして恐れ入ります。`
- `確認が遅れまして大変申し訳ございませんでした。{{原因}}のため、確認が行えておりませんでした。大変申し訳ございません。`

## 7. 日程調整モード（カレンダー連携）

> 仕組みに組み込む機能。フレーズ集というより「動作」のメモ。

- **候補日を送る**とき：自分のGoogleカレンダーの空きを自動抽出（平日/時間帯の条件つき）→ 1-2の「候補日を送る」テンプレに差し込む。
- **相手が確定**したら：Googleカレンダーに予定を作成（`addGoogleMeetUrl`でMeet URL発行）→ 出席者を入れれば招待も送付。本文には1-3の確定テンプレ＋会議URL。
- ⚠️ **Teams URLは自動発行不可**（Microsoft側の機能）。Teams希望の相手には手動でURL発行して本文に貼る。

## 気づき（傾向メモ）
- 相手の呼称は基本 `{{宛名}}様`。社名は初回や複数社宛のときに添える。
- 一文が丁寧で、クッション言葉（`恐れ入りますが` `大変恐縮ですが` `生憎`）を多用。
- 依頼は必ず理由（`〜の都合上`）とセットで、期日は「{{N}}営業日まで」で伝える。
- 会議調整は「候補日を箇条書き→ご都合を伺う→確定したら会議URL発行」の型が固定。
- 署名は `Nature / 三矢` の短い版と、フルの2段構え。
