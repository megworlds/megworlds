Gmail 業務自動化 / 権限相談メモ

定期実行で「都度確認」が壁になっている件

受信メールの仕分けと返信下書きを定期実行で自動化したい。ただし定期実行は無人で起動するため、Gmailツールの「都度確認」承認が押せず毎回止まってしまう。回避策の可否をエンジニアに確認したい。

相談者 三矢（Growth Circle） 対象 mmitsuya@nature.global の Gmail 前相談 2026-08-03 / 黒田さん

01 やりたいこと

人の手を介さず、決まった時刻に受信箱を整えて返信の下書きまで用意する。

受信メールを内容で仕分け（ラベル付け）し、返信が必要なものには三矢の文体で返信下書きを自動作成する。最終的な送信は必ず本人がボタンを押す——AIは下書きどまり。日程調整のメールだけ、カレンダーの空きを見て候補出し／仮押さえも行う。

02 使うツールと、絶対にやらないこと

権限は最小限。破壊的・外向きの操作は仕組みとして持たせていない。

使うツール
  • create_draft 返信の下書き作成
  • create_label ラベル作成
  • label_thread スレッドにラベル付与
  • Calendar: list / create_event（日程調整時のみ・招待は送らない設定）
やらないこと
  • メールの送信（send）
  • メールの削除・Trash / Spam 移動
  • 予定の外部出席者への招待送信
  • 本人アカウント以外への操作

03 どこで詰まるか

定期実行（無人起動）と「都度確認」承認が噛み合わない。

定期実行が決まった時刻に無人で起動する
Gmailツール（下書き作成／ラベル付け）を呼び出す
権限が「都度確認」しか選べず、承認待ちで停止する
承認する人がいないため、毎回失敗して終わる

「常に許可」にしようとすると出るメッセージ

「常に許可」は管理者によって無効化されています。組織設定 → Cowork で有効にするよう管理者に依頼してください。

04 混同しやすい「2つの権限」

① を管理者が開けるか、②で迂回できるか——ここが相談の核心。

1

コネクタのツール権限（常に許可／都度確認／許可しない）

組織レベル設定
管理者のみ変更可
現在ロック中。 組織設定 → Cowork → コネクタ → Gmail。「常に許可」が組織ポリシーで無効化されており、本人では解除できない。
2

セッション／ルーチンの実行モード（auto mode）

ルーチン毎に選択
本人で変更可
迂回策の候補。 ルーチンを auto（自動承認）モードで動かすと都度承認がスキップされる。8/3 の相談で黒田さんの見立て：②の auto mode で同じ指示を出せば ① が無くても承認で止まらないはず。黒田さんの手元では auto mode でラベル作成・付与が承認無しで成功した。

05 エンジニアに確認したいこと

この4点がクリアになれば定期実行を組める。

  1. auto 実行モードで定期実行すれば、①の「常に許可」ロックが無くても下書き作成・ラベル付けまで通るか？ ＝ 黒田さんの見立ての最終確認。通るなら管理者対応は不要。
  2. 通らない場合、①のロック解除は可能か？（組織設定 → Cowork → コネクタ → Gmail の create_draft / create_label / label_thread を「常に許可」に） ＝ その3ツールだけ。送信・削除系は許可しないままでよい。
  3. どのサーフェスで動かすのが正解か。Cowork の Scheduled task か、Claude Code の routine か？ ＝ auto mode が使えるのはどちらか、社内の推奨はどちらか。
  4. Gmail コネクタの認証が切れると定期実行が止まる。再認証の運用や延命の方法はあるか？ ＝ 実際に一度 token expired で下書き作成に失敗した。無人運用での再接続フローを知りたい。

06 承認をスキップしても事故らない理由

auto mode を許しても、被害の出る操作は仕組み側で塞いである。

  • ✓
    触るのは下書きとラベルだけ。送信・削除・Trash / Spam は対象外（ツールとして持たせない）。
  • ✓
    最終的な送信は必ず人（三矢）がボタンを押す。AIが勝手に外へ出すことはない。
  • ✓
    操作対象は本人の Gmail のみ。他人のアカウントには触れない。
  • ✓
    カレンダーの予定作成も招待メールを送らない設定（本人カレンダーの押さえにとどめる）。
